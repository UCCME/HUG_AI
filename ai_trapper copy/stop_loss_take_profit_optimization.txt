优化方案1：放宽反向信号条件（⭐⭐⭐⭐⭐ 最重要！必须实施）
================================================================================

【当前代码】位于 luxy_strategy.py 约580-592行
-------------------------------------------------
# 3. 反向信号（仅强反向信号才平仓）
ut_signal = data['UT_Signal'].iloc[index]
st_direction = data['ST_Direction'].iloc[index]

if position.direction == 1:  # 多头持仓
    # UT Bot卖出信号 + SuperTrend转空
    if ut_signal == -1 and st_direction == -1:
        return True, "强反向信号", position.remaining_size
else:  # 空头持仓
    # UT Bot买入信号 + SuperTrend转多
    if ut_signal == 1 and st_direction == 1:
        return True, "强反向信号", position.remaining_size
-------------------------------------------------

【问题】
只要2个条件满足就平仓：
1. UT Bot反向
2. SuperTrend反向

在5分钟级别，这两个指标经常在正常回调中反转，导致过早平仓。


【优化后代码】
-------------------------------------------------
# 3. 反向信号（需要更强确认才平仓）
ut_signal = data['UT_Signal'].iloc[index]
st_direction = data['ST_Direction'].iloc[index]
adx = data['ADX'].iloc[index]
adx_prev = data['ADX'].iloc[index-1] if index > 0 else adx
vol_ratio = data['Volume_Ratio'].iloc[index]

if position.direction == 1:  # 多头持仓
    # 需要4个条件同时满足才平仓：
    # 1. UT Bot卖出信号
    # 2. SuperTrend转空
    # 3. ADX下降（趋势减弱）
    # 4. 成交量放大（确认反转）
    strong_reversal = (
        ut_signal == -1 and 
        st_direction == -1 and
        adx < adx_prev and          # ADX下降
        vol_ratio > 1.3             # 成交量放大确认
    )
    
    if strong_reversal:
        return True, "强反向信号", position.remaining_size
        
else:  # 空头持仓
    # 同样的逻辑
    strong_reversal = (
        ut_signal == 1 and 
        st_direction == 1 and
        adx < adx_prev and
        vol_ratio > 1.3
    )
    
    if strong_reversal:
        return True, "强反向信号", position.remaining_size
-------------------------------------------------

【修改说明】
1. 增加ADX下降条件：
   - adx < adx_prev
   - 确认趋势正在减弱，而非仅仅是回调

2. 增加成交量确认：
   - vol_ratio > 1.3
   - 要求成交量放大，确认是真正的反转而非假突破

【预期效果】
- 强反向信号占比：55.8% → 15-25%
- TP止盈占比：22.8% → 50-65%
- 平均R倍数：0.42R → 1.5-2.0R
- 盈亏比：0.98 → 2.0-2.5
- 总收益：-0.84% → +15-25%
