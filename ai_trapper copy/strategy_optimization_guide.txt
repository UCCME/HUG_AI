1. 【止盈参数优化】- 提高盈亏比
--------------------------------------------------------------------------------
当前配置：
  TP1 = 1.5R (33%)
  TP2 = 2.0R (33%)  
  TP3 = 3.0R (34%)

优化建议A - 更激进的盈亏比（适合趋势市场）：
  TP1 = 2.0R (25%)   # 第一目标提高到2R
  TP2 = 3.0R (25%)   # 第二目标提高到3R
  TP3 = 5.0R (50%)   # 第三目标大幅提高到5R
  
  预期效果：
  ✓ 盈亏比可能从2.0提升到3.0+
  ✗ 触及TP3的概率降低，可能减少盈利次数
  
优化建议B - 更保守的分批（提高胜率）：
  TP1 = 1.0R (40%)   # 更快锁定部分利润
  TP2 = 2.0R (30%)   
  TP3 = 3.0R (30%)   
  
  预期效果：
  ✓ 胜率可能提升5-10%
  ✗ 平均盈亏比可能降低到1.5-1.8


2. 【追踪止损优化】- 提高利润捕获
--------------------------------------------------------------------------------
当前配置：
  TRAILING_STOP_ACTIVATION = 1.5R
  UT_SMOOTHING = 0.3

优化建议A - 更早激活追踪（锁定利润）：
  TRAILING_STOP_ACTIVATION = 1.0R  # 从1.5R降低到1.0R
  UT_SMOOTHING = 0.4              # 提高平滑度，减少假突破
  
  预期效果：
  ✓ 更早保护利润，减少回撤
  ✗ 可能过早退出趋势

优化建议B - 更激进追踪（捕获大趋势）：
  TRAILING_STOP_ACTIVATION = 2.0R  # 提高到2.0R
  UT_SMOOTHING = 0.2              # 降低平滑度，快速跟随
  
  预期效果：
  ✓ 在强趋势中捕获更大利润
  ✗ 回撤风险增加

4. 【仓位管理优化】
--------------------------------------------------------------------------------
当前配置：
  POSITION_SIZE = 0.15 (15%)

优化建议A - 凯利公式动态仓位：
  根据历史胜率和盈亏比动态调整：
  Kelly% = (胜率 × 平均盈利 - (1-胜率) × 平均亏损) / 平均盈利
  
  实现方式：
  - 在config中添加 USE_KELLY_SIZING = True
  - 在策略中实现kelly_position_size()方法
  - 设置最大仓位限制（如：MAX_POSITION_SIZE = 0.25）

优化建议B - 固定金额风险：
  每笔交易风险固定金额：
  RISK_PER_TRADE = 2000  # 每笔最多亏损2000美元（2%）
  position_size = RISK_PER_TRADE / (entry_price - stop_loss)
  
  预期效果：
  ✓ 风险更可控
  ✓ 适应不同波动率

  1. 在数据加载时重采样为15分钟和1小时

  3. 只在高时间框架趋势一致时开仓

  ```python
  # 15分钟趋势
  df_15m = resample_to_15m(df_5m)
  st_15m_direction = calculate_supertrend(df_15m)
  
  # 开仓条件
  if signal_5m == BUY and st_15m_direction == 1:

  ```

  ✓ 胜率提升10-15%
  ✓ 捕获更大级别趋势
  ✗ 交易频率降低30%


2. 【市场状态识别】★★★★☆（推荐）
--------------------------------------------------------------------------------
当前问题：
  在震荡市和趋势市使用相同参数，效果不佳

优化方案：
  识别市场状态，动态调整参数：
  
  状态1 - 强趋势市（ADX > 30）：
    - 使用更宽的止损（2.5×ATR）
    - 更高的TP目标（2R/3R/5R）
    - 激活追踪止损的阈值提高（2.0R）
  
  状态2 - 弱趋势市（20 < ADX < 30）：
    - 使用当前默认参数
  
  状态3 - 震荡市（ADX < 20）：
    - 暂停交易或使用震荡策略
  
  实现方式：
  ```python
  def get_market_regime(adx):
      if adx > 30:
          return 'STRONG_TREND'
      elif adx > 20:
          return 'WEAK_TREND'
      else:
          return 'RANGING'
  ```
  
  预期效果：
  ✓ 在合适的市场环境使用合适的策略
  ✓ 整体盈亏比提升20-30%


3. 【波动率自适应】★★★★☆（推荐）
--------------------------------------------------------------------------------
当前问题：
  参数固定，不适应市场波动率变化

优化方案：
  基于ATR百分比动态调整参数：
  
  ```python
  # 计算波动率百分比
  volatility_pct = (ATR / Close) * 100
  
  # 低波动（<1%）
  if volatility_pct < 1.0:
      multiplier = 1.5  # 降低止损倍数
      tp_multiplier = 1.5  # 降低止盈目标
  
  # 高波动（>2%）
  elif volatility_pct > 2.0:
      multiplier = 2.5  # 提高止损倍数
      tp_multiplier = 1.0  # 保持止盈目标
  
  # 正常波动
  else:
      multiplier = 2.0
      tp_multiplier = 1.0
  ```
  
  预期效果：
  ✓ 适应不同市场环境
  ✓ 减少在高波动时被扫损


4. 【增加Donchian通道】★★★☆☆
--------------------------------------------------------------------------------
来自Luxy策略的重要特性：

Donchian通道用途：
  1. 作为额外的支撑/阻力确认
  2. 动态止损的补充
  3. 突破信号确认
  
  实现方式：
  ```python
  def calculate_donchian(high, low, period=20):
      don_high = high.rolling(period).max()
      don_low = low.rolling(period).min()
      don_mid = (don_high + don_low) / 2
      return don_high, don_low, don_mid
  
  # 在止损计算中使用
  def calculate_stop_loss_with_donchian():
      base_sl = entry - ATR * 2.0
      don_sl = donchian_low
      return max(base_sl, don_sl)  # 取更优的止损位
  ```


5. 【VWAP支撑/阻力】★★★☆☆
--------------------------------------------------------------------------------
VWAP（成交量加权平均价）是重要的机构交易者参考线

优化方案：
  1. 作为趋势过滤器
  2. 作为止损参考
  3. 作为反转确认
  
  实现方式：
  ```python
  # 计算VWAP
  vwap = (df['Close'] * df['Volume']).cumsum() / df['Volume'].cumsum()
  
  # 在信号生成中使用
  if signal == BUY:
      if close > vwap:  # 价格在VWAP上方
          confidence += 0.1
  ```


6. 【部分对冲】★★☆☆☆（高级）
--------------------------------------------------------------------------------
在极端行情中保护利润：

实现方式：
  当持有多头且盈利≥2R时：
  - 开一个小的空头对冲（例如30%仓位）
  - 锁定部分利润
  - 在趋势恢复时平掉对冲
  
  预期效果：
  ✓ 减少回撤
  ✗ 增加交易复杂度和手续费

1. 【最大回撤控制】★★★★★（强烈推荐）
--------------------------------------------------------------------------------
当前问题：
  没有动态回撤控制

优化方案：
  ```python
  MAX_DRAWDOWN_PCT = 0.15  # 最大允许回撤15%
  
  def check_drawdown():
      current_drawdown = (peak_equity - current_equity) / peak_equity
      
      if current_drawdown > MAX_DRAWDOWN_PCT:
          # 暂停交易或降低仓位
          POSITION_SIZE = POSITION_SIZE * 0.5
          return True
      return False
  ```
  
  预期效果：
  ✓ 保护账户
  ✓ 避免在连续亏损时过度交易


2. 【每日最大交易次数】★★★★☆
--------------------------------------------------------------------------------
避免过度交易：

  ```python
  MAX_TRADES_PER_DAY = 3
  
  daily_trade_count = 0
  current_date = None
  
  def can_open_position(timestamp):
      if timestamp.date() != current_date:
          daily_trade_count = 0
          current_date = timestamp.date()
      
      return daily_trade_count < MAX_TRADES_PER_DAY
  ```

  ```python
  MAX_CONSECUTIVE_LOSSES = 3
  ```
