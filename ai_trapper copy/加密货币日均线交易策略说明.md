## 🎯 策略核心四步

### 第一步：只选"会涨的币" —— MACD金叉

**买入信号：MACD金叉**

- 打开**日线图**，只看一件事：MACD金叉
- **最佳信号**：MACD在0轴**上方**金叉，命中率最高
- 不看新闻，不听消息，只看技术指标

**什么是MACD金叉？**
- MACD线（快线）从下向上穿过信号线（慢线）
- 表示短期趋势开始强于长期趋势，可能开始上涨

---

### 第二步：只用一条线操作 —— 日均线

**持仓判断：日均线**

规则极其简单：
- 币价在日均线**之上** → 继续持有
- 币价跌破日均线 → **立即卖出**

**记住这句话：**
> 在线上，拿着；在线下，跑了。

---

### 第三步：仓位管理 —— 观察两件事

**全仓买入条件：**

同时满足以下条件才全仓买入：
1. ✅ 价格站上日均线
2. ✅ 成交量也站上成交量均线
3. ✅ MACD出现金叉

**分批止盈规则：**

| 涨幅 | 操作 | 说明 |
|------|------|------|
| 涨40% | 卖出1/3 | 锁定第一波利润 |
| 涨80% | 再卖1/3 | 锁定第二波利润 |
| 跌破日均线 | 剩余全部卖出 | 严格止损 |

**这是纪律，不是讨论！**

---

### 第四步：止损只有一句话

**止损规则：**

- 跌破日均线 → 第二天**无论什么理由**，清仓
- **没有例外**，侥幸一次，前功尽弃

**错过了怎么办？**

- 不要追高！
- 等它**重新站上日均线**，再买回来就是了
- 宁可错过，不要做错

## 📊 技术指标说明

### MACD指标

**组成：**
- MACD线（快线）= 12日EMA - 26日EMA
- 信号线（慢线）= MACD的9日EMA
- 柱状图 = MACD线 - 信号线

**金叉信号：**
- MACD线从下向上穿过信号线
- 柱状图由负转正
- 在0轴上方金叉更强

### 日均线（MA）

**计算方法：**
- 将过去N天的收盘价相加，除以N
- 本策略默认使用20日均线
- 也可以使用其他周期（如30日、60日）

**作用：**
- 判断趋势方向
- 作为支撑/压力位
- 作为买卖决策依据

### 成交量均线

**作用：**
- 确认价格走势的有效性
- 价格和成交量同时放大 → 趋势更可靠
- 量价配合 → 提高胜率

## 🔧 策略参数

### 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 日均线周期 | 20日 | 可根据个人习惯调整 |
| MACD快线 | 12 | 标准MACD参数 |
| MACD慢线 | 26 | 标准MACD参数 |
| MACD信号线 | 9 | 标准MACD参数 |
| 第一止盈位 | 40% | 可适当调整 |
| 第二止盈位 | 80% | 可适当调整 |
| 止盈比例 | 1/3 | 每次卖出三分之一 |

### 参数调优建议

**日均线周期：**
- 20日：适合短期趋势
- 30日：适合中期趋势  
- 60日：适合长期趋势

**止盈位：**
- 保守型：30% / 60%
- 标准型：40% / 80%
- 激进型：50% / 100%

### 基本使用

```python
import pandas as pd
from crypto_ma_strategy import CryptoMAStrategy

# 1. 准备数据（需要包含收盘价和成交量）
df = pd.DataFrame({
    'close': [100, 102, 105, 108, 110, ...],    # 收盘价
    'volume': [1000, 1200, 1500, 1300, ...]     # 成交量
}, index=pd.date_range('2024-01-01', periods=100))

# 2. 创建策略实例
strategy = CryptoMAStrategy(
    ma_period=20,           # 20日均线
    profit_target_1=0.40,   # 涨40%第一次止盈
    profit_target_2=0.80    # 涨80%第二次止盈
)

# 3. 运行回测
results = strategy.backtest(df, initial_capital=100000)

# 4. 获取当前交易信号
signal = strategy.get_current_signal(df)
print(f"当前价格: {signal['price']}")
print(f"日均线: {signal['ma']}")
print(f"是否买入: {signal['should_buy']}")
print(f"是否卖出: {signal['should_sell']}")
```

- 📉 最大回撤

## ❓ 常见问题

### Q1: 如果MACD金叉了，但价格没有站上均线怎么办？

A: **不买入**。必须同时满足三个条件：MACD金叉 + 价格站上均线 + 成交量站上均线。

### Q2: 卖出后如果立即反弹怎么办？

A: **不要后悔**。止损是为了保护本金。等它重新站上均线，再买回来就是了。

### Q3: 可以使用其他均线周期吗？

A: **可以**。但建议新手先使用20日均线，等熟练后再调整参数。

### Q4: 止盈一定要分三次吗？

A: **不一定**。可以根据个人风格调整，但一定要有止盈纪律。

### Q5: 熊市中这个策略还有效吗？

A: **有效**。因为有严格的止损规则，熊市中会及时离场，避免深度套牢。

### Q6: 需要每天盯盘吗？

A: **不需要**。每天看一次日线图就够了，最好在收盘前判断信号。
